# Amruth Portfolio

A modern, high-performance developer portfolio built with Next.js 15, React 19, and Framer Motion. This project features an immersive developer-centric UI including a terminal-style landing, a VS Code project explorer, and a GitHub-style journey timeline.

## 🚀 Tech Stack

- **Frontend**: Next.js 15 (App Router), React 19, TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Email**: EmailJS

## ✨ Key Features

- **Terminal Landing**: An interactive terminal-themed intro.
- **VS Code Project Explorer**: A realistic IDE-style interface for browsing projects.
- **Git Journey**: A GitHub-style commit log for professional experience.
- **Responsive Design**: Optimized for all devices (mobile to desktop).
- **Dark/Light Mode**: Seamlessly switches between developer workspace themes.

## 🏗️ Featured Projects

- **Stratify**: Multi-tenant SaaS Project Management platform.
- **Speedo**: GPS Fleet Trip Analytics system with GIS visualization.
- **FashionZone**: Full-stack E-commerce platform with payment integration.

## 🛠️ Installation & Setup

1. **Clone the repo**
   ```bash
   git clone https://github.com/AmruthAmruth/Amruth-Portfolio.git
   cd Amruth-Portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Environment Variables**
   Create a `.env.local` file and add your EmailJS keys:
   ```env
   NEXT_PUBLIC_EMAILJS_SERVICE_ID=your_service_id
   NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=your_template_id
   NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=your_public_key
   ```

4. **Run Development Server**
   ```bash
   npm run dev
   ```

## 📂 Project Structure

- `app/`: Next.js App Router pages and layouts.
- `components/`: Modular UI components (sections and shared).
- `constants/`: Global constants and project data.
- `theme/`: Styling tokens and animation configs.
